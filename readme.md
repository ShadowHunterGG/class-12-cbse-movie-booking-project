# Movie Booking Application

A movie booking application using Tkinter and MySQL.

## Features

- User Login and Signup
- Browse Movies
- View Posters
- Ticket Booking
- Calendar Integration

## Admin Panel Access

For demonstration purposes, the admin panel can be accessed using the following credentials:

Username: `admin`
Password: `123456`

## Installation

Install dependencies:

pip install -r requirements.txt

## Database Setup

Run database_setup.sql in MySQL.

Create config.py from config_example.py and enter your MySQL credentials.

## Run

python main.py
